# BlogBay

BlogBay is a responsive blog application developed for the IN2120 Web Programming Take Home Assignment.

## Technologies

- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Main Features

- User registration
- User login and logout
- Secure password hashing
- Create blog posts
- Upload featured images
- View all blog posts
- View a single blog post
- Edit personal blog posts
- Delete personal blog posts
- User authorization
- User profile management
- Six blogs per page with pagination
- Responsive maroon-and-white interface

## Database Setup

1. Create a database named `blog_db`.
2. Import the file:

   `database/blog_db.sql`

3. Update the database settings in `config.php` when required.

## Local Setup

1. Place the project folder inside:

   `C:\xampp\htdocs`

2. Start Apache and MySQL through XAMPP.

3. Open:

   `http://localhost/blog_app`
